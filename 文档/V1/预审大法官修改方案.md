# 环境生命周期与预审极简重构计划

## 背景

现有预审系统已部分实现极简化：

- `preTrialJudgePrompt.ts` 已精简为只输出 `missing_info` 判定
- `IntentClarification.tsx` 已有 TARGET/DURATION 两种前端硬编码模式
- `battleSlice.ts` 已有 `globalEffects` 数组

**但存在以下问题**：

1. 预审法官仍输出 `confirmed_action`（包含 action_type 等数值字段），未完全阉割
2. `globalEffects` 没有生命周期递减逻辑（`turns_left` 不递减）
3. 上帝指令是一次性的，无法跨回合持续生效

## 阶段 4：生命周期心跳与动态注入

### 修改文件：`src/features/battle/battleSlice.ts`

#### 4.1 状态定义修改

```typescript
// 替换 globalEffects
activeModifiers: ActiveModifier[];

// 新增方法
injectModifier: (description: string, turns: number) => void;
tickModifiers: () => void;
```

#### 4.2 injectModifier 实现

```typescript
injectModifier: (description: string, turns: number) => {
  const modifier: ActiveModifier = {
    id: crypto.randomUUID(),
    description,
    turns_left: turns,  // -1 表示永久
    source: 'PLAYER_COMMAND',
    createdAt: Date.now(),
  };
  set((state) => ({
    activeModifiers: [...state.activeModifiers, modifier],
  }));
},
```

#### 4.3 tickModifiers 实现

在 `nextTurn()` 回合结束时调用：

```typescript
tickModifiers: () => {
  set((state) => ({
    activeModifiers: state.activeModifiers
      .map(m => ({
        ...m,
        turns_left: m.turns_left === -1 ? -1 : m.turns_left - 1,
      }))
      .filter(m => m.turns_left === -1 || m.turns_left > 0),
  }));
},
```

#### 4.4 修改 nextTurn()

在每回合结束时（第 1274 行附近）添加：

```typescript
// 回合结束时触发修饰器心跳
get().tickModifiers();
```

#### 4.5 动态上下文拼接

在调用【裁判 Judge】或【演员 Actor】之前，读取 activeModifiers：

```typescript
const activeModifiers = get().activeModifiers;
const modifiersContext = activeModifiers
  .map(m => `- ${m.description} (剩余${m.turns_left}回合)`)
  .join('\n');

const systemPrompt = `
...
【当前生效的环境效果】：
${modifiersContext || '无'}
`;
```
