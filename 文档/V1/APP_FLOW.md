# 应用流程文档 (APP_FLOW)

---

## 1. 原则

| 原则    | 说明                    |
| ----- | --------------------- |
| 无死胡同  | 任何错误状态必须提供"重试"或"返回"按钮 |
| 状态持久化 | 刷新页面后保持当前状态和资源        |

---

## 2. 路由结构

| 路径           | 页面             | 说明          |
| ------------ | -------------- | ----------- |
| `/`          | SplashScreen   | 启动页，2秒后自动跳转 |
| `/hub`       | HubView        | 客厅主场景       |
| `/shop`      | ShopView       | 商店页面        |
| `/inventory` | InventoryView  | 背包页面        |
| `/arena`     | ArenaView      | 斗兽场（战斗入口）   |
| `/agent`     | AgentDashboard | 演员管理面板      |

## 5. 错误处理

### 5.1 全局错误边界

| 错误类型          | 处理方式                                      |
| ------------- | ----------------------------------------- |
| API 超时 (>10s) | 收音机填充，后台静默重试，仍失败则暂停战斗                     |
| 网络断开          | 弹窗 "Signal Lost"，按钮 "Reconnect"           |
| 数据损坏          | 弹窗 "Corrupted Signal"，按钮 "Reset Universe" |
| 金币不足          | Toast 提示，不扣除                              |

### 5.2 战斗错误

| 场景         | 处理                       |
| ---------- | ------------------------ |
| AI 响应异常    | 标记该轮重试，显示 "Receiving..." |
| API Key 无效 | 弹窗提示更换，显示错误信息            |
| 干预队列积压     | 显示队列长度，限制新干预             |

## 7. 关键系统说明

### 7.1 Pre-Trial Judge (预审法官)

上帝指令输入后，经过预审法官审查：

- **REJECTED**: 拦截违规指令（如直接修改数值）
- **VALID + 需要澄清**: 显示澄清 UI (TARGET/DURATION)
- **VALID**: 插入指令队列，下一轮生效

### 7.2 Buff 系统

所有 Buff 效果已从 LLM 转移到 TypeScript 硬编码：

- `TAUNT`: 强制攻击嘲讽者
- `ATK_UP`: 伤害 x1.5
- `DEF_UP`: 伤害 x0.5
- `HEAL_OVER_TIME`: 每回合回复 10% HP

### 7.3 场景系统

| 场景 ID             | 名称         | 规则     |
| ----------------- | ---------- | ------ |
| `tiktok_battle`   | TikTok 流量战 | 流量即生命值 |
| `island_survival` | 荒岛大逃杀      | 经典大逃杀  |
| `casino_night`    | 星际赌场       | 运气与策略  |

### 7.4 经验系统

| 来源   | 数值范围      |
| ---- | --------- |
| 喂食零食 | +5 ~ +100 |
| 对话聊天 | -2 ~ +5   |
