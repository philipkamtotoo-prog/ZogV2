## 一、useGameStore（玩家经济系统）

### 1. gold - 金币 💰

| 属性 | 值 |
|------|-----|
| 类型 | `number` |
| 初始值 | `GAME_CONFIG.INITIAL_GOLD` (100) |
| 存储位置 | `src/stores/index.ts:105` |
| 来源 | 挂机产出 (`useIdleIncome`)、战斗奖励、拾荒 |
| 消耗 | 购买物品、升级设备 |
| 显示位置 | 顶部栏 `💰 {gold.toFixed(0)}` |

### 2. inventory - 物品库存

| 属性 | 值 |
|------|-----|
| 类型 | `Record<string, number>` |
| 结构 | `{ itemId: quantity }` |
| 存储位置 | `src/stores/index.ts:108` |
| 数据流 | 购买 → `buyItem()` → 写入 inventory → 页面渲染 ownedSnacks |
| 显示位置 | 零食柜列表 |

### 3. consumeSnack - 零食消耗方法

| 属性 | 值 |
|------|-----|
| 类型 | `(itemId: string) => boolean` |
| 位置 | `src/stores/index.ts` |
| 逻辑 | 库存-1 → 调用 `addExp()` |
| 触发 | 零食按钮点击 `handleFeed()` |

## 二、useIdleIncome（挂机收益系统）

### 1. incomePerMinute - 每分钟收益

| 属性 | 值 |
|------|-----|
| 类型 | `number` |
| 计算公式 | `baseRate(40) × multiplier(等级加成)` |
| 存储 | `src/hooks/useIdleIncome.ts:35` |
| 显示 | 顶部栏 `📈 {incomePerMinute.toFixed(1)} G/min ({location})` |

**等级加成表：**

| 等级 | 倍率 | 实际收益 |
|------|------|----------|
| 1-2 | 1.0x | 40 G/min |
| 3-4 | 1.1x | 44 G/min |
| 5-6 | 1.2x | 48 G/min |
| 7-8 | 1.3x | 52 G/min |
| 9 | 1.5x | 60 G/min |
| 10+ | 2.0x | 80 G/min |

### 2. isActive - 挂机状态

| 属性 | 值 |
|------|-----|
| 类型 | `boolean` |
| 当前值 | 始终 `true` |
| 用途 | 控制收益显示栏是否显示 |

### 3. location - 挂机位置

| 属性 | 值 |
|------|-----|
| 类型 | `string` |
| 当前值 | `'挂机中'` |
| 显示 | 顶部收益栏 |

## 三、useZogStore（Zog 角色系统）

### 1. level - 信任等级 ★

| 属性 | 值 |
|------|-----|
| 类型 | `number` |
| 初始值 | `1` |
| 存储位置 | `src/features/zog/zogSlice.ts:117` |
| 增长方式 | 喂食零食 (`addExp`) |
| 显示 | 顶部栏 `Lv.{level}` + 经验条 `{exp} XP` |

### 2. exp - 经验值

| 属性 | 值 |
|------|-----|
| 类型 | `number` |
| 初始值 | `0` |
| 无上限 | ✅ 经验可以无限累积 |
| 获取途径 | 喂食零食、聊天 |
| 显示 | 顶部栏 `(exp} XP)` |

### 3. currentState - 当前状态

| 属性 | 值 |
|------|-----|
| 类型 | `string` |
| 初始值 | `'IDLE_SOFA'` |
| 常见状态 | `IDLE_SOFA`, `BUSY_FRIDGE`, `SCAVENGING`, `CHATTING` |
| 存储位置 | `src/features/zog/zogSlice.ts:106` |
| 显示位置 | Dev探针 + 底部导航栏 |

**状态列表：**

```typescript
'IDLE_SOFA'      // 闲置中
'BUSY_FRIDGE'    // 忙于冰箱
'SCAVENGING'     // 拾荒中
'CHATTING'       // 聊天中
```

### 4. currentScript - 当前剧本

| 属性 | 值 |
|------|-----|
| 类型 | `object | null` |
| 初始值 | `null` |
| 生成方式 | `generateDailyScript()` 调用 LLM |
| 持久化 | ✅ 存入 IndexedDB |
| 显示 | Dev探针 JSON 查看器 |

### 5. isAway - 是否离开

| 属性 | 值 |
|------|-----|
| 类型 | `boolean` |
| 初始值 | `false` |
| 显示 | Dev探针 `🏠 HOME` / `🚫 AWAY` |

### 6. currentLine - 当前台词/想法

| 属性 | 值 |
|------|-----|
| 类型 | `string | null` |
| 初始值 | `null` |
| 来源 | 剧本中的台词、tick 触发 |
| 显示 | Dev探针 `Current Thought` 区域 |

### 7. generateDailyScript - 生成剧本方法

| 属性 | 值 |
|------|-----|
| 类型 | `() => Promise<void>` |
| 按钮 | Dev探针 `🔄 强制生成今日剧本` |
| 作用 | 调用 LLM 生成新剧本 |

### 8. addExp - 增加经验方法

| 属性 | 值 |
|------|-----|
| 类型 | `(amount: number, source: 'GIFT' | 'CHAT') => void` |
| 来源 | `handleFeed()` 喂食时调用 |
| 逻辑 | `exp += amount` → 检查升级 |

## 九、零食柜数据流详解

```
SNACK_SHOP_ITEMS (constants)
    │
    ├── id: 'used_battery'
    ├── name: '二手干电池'
    ├── icon: '🔋'
    ├── price: 50
    └── expBonus: 5
    │
    ▼ map
ownedSnacks = [
  { ...item, count: inventory[item.id] },
  ...
]
    │
    ▼ filter (count > 0)
显示零食列表
    │
    ▼ 点击按钮
handleFeed(itemId)
    │
    ├─► consumeSnack(itemId)  // 库存-1
    └─► addExp(item.expBonus, 'GIFT')  // 加经验
```

## 十一、改造注意事项

### 添加新字段到顶部资源栏

1. 在对应的 Store 中添加字段（如 `useGameStore` 或 `useZogStore`）
2. 在 `HubView.tsx` 的 `header` 区域添加展示逻辑

### 添加新零食

1. 在 `SNACK_SHOP_ITEMS` 常量中添加新条目
2. 字段：`id`, `name`, `icon`, `price`, `expBonus`, `description`, `category`

### 添加新路由

1. 在 `ROUTES` 常量中添加新路径
2. 在页面中添加对应的 `navigate()` 按钮

### 修改挂机收益

1. 修改 `useIdleIncome.ts` 中的 `baseRate` 或 `getIncomeMultiplier()` 函数
2. 注意：收益每 10 秒结算一次
