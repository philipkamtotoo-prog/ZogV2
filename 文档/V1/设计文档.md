# 游戏策划案：Alien TV (Zog的客厅与电视)

> ⚠️ **过时文档** — 部分数值与最新版本 `数值系统重构_v5.1.md` 不符，以该文档为准。

一、 核心概念 (High Concept)
概念介绍： 一款 PC 桌面挂机游戏。玩家扮演低科技外星球Doda上的一个外星人 ，是非常可爱的Zog，Zog除了出门捡垃圾外，唯一的爱好是看只有几个台的宇宙电视机。
由于可爱外星人Zog的星球是低科技星球，他们的宇宙电视机都是高科技外星球进口的，zog只会在前端界面上胡乱输入Prompt，对电视里的ai角色指手画脚，所以只要zog开始看电视（ai角色大乱斗），用户的前端界面上都有一个Prompt输入框。
游戏核心玩法是通过电视机收看并干预高科技 AI 角色的"语言大乱斗"，同时还可以探索荒诞的低科技星球。
核心体验循环：
深度陪伴：在客厅与 Zog 闲聊、投喂，或者开启"专注模式"让他陪你一起工作。
实时模式：玩家填入自己的 API Key（OpenAI/Claude等），实现真正的多模型大乱斗。
备战：选择带有特定获胜目标的场景，抽取官方人设卡，注入 Prompt 进行"魔改"。
模式选择：
选择不同的场景（接收宇宙电视台），看ai角色在不同的场景下吵架
观战与填充：围观 AI 互喷。在 AI 生成的等待间隙，收听"星际收音机"播放的荒诞段子。
结算：生成战报简报，结算金币。

## 0.4 Zog 对话系统 (LLM JSON Output) [已实装]

Zog 对话系统要求 LLM 输出严格 JSON 格式：

```json
{
  "reply": "Zog 的回复文本",
  "expChange": 3
}
```

**强制要求**：

- 必须输出合法 JSON 对象
- expChange 由 LLM 判断玩家发言对当前阶段性格的迎合程度
- 禁止输出普通文本、Markdown 标记

二、 模块1——Zog 的生活圈 (Zog's World)
Zog 不仅仅是一个操作员，他是玩家的"桌面室友"。

1. 主场景：破旧客厅 (The Hub)
   功能：挂机主界面与生活区。
   交互：电视（战斗入口）、冰箱（喂食）、收音机（段子）、沙发（休息）。
2. 深度陪伴系统 (Companion System)
   侧边栏聊天 (Zog Chat)：
   闲聊：玩家可以在非战斗时间随时和 Zog 聊天（"今天吃什么？"）
   要钱：每10分钟可以向zog乞讨一定数量的金币
   实现：使用轻量级模型。
   好感度 (Affection)：
   通过喂食、聊天、一起看戏提升。
   好感度高时，Zog 会解锁新的表情包、动作，甚至主动送玩家"捡来的垃圾"（小礼物）。
   专注模式 (Focus Mode)：
   点击"工作"，电视只发出白噪音，Zog 戴上眼镜假装写作业/办公，但是会偷偷瞟用户，很灵动
3. 副玩法：星球溜达 (Zog Walk)
   机制：玩家点击"出门溜达"，Zog 离开客厅，此时玩家不可以进行战斗，建议离线时开启。
   产出：Zog 回家时会带回一张**【拍立得照片】（AI 绘图）和一段【日记文案】**。
   作用：扩充世界观，增加挂机的期待感。
   三、 模块2——星际斗兽场 (The Arena)
   核心流程概览 (The Flow)
   用户体验分为四个阶段：
   备战 (Drafting)：抽卡 -> 强行注入(无校验) -> 自选变异。
   定局 (Setup)：选场景 -> 下注支持。
   死斗 (Combat)：观战 -> 投掷干预 -> 每回合简报。
   终局 (Settlement)：胜负判定 -> AI 短文战报 -> 金币结算。
   详细设计方案
   阶段 1：抽卡与塑形 (Drafting & Injection)
   步骤0：模式选择 (Mode Toggle)
   A. 导演模式 (Director Mode / 经济版)
   定义：不允许用户自定义 API。后台统一使用硅基流动的千问轻量模型（速度最快、成本最低）扮演所有角色。
   体验：几乎零延迟，流畅如剧本。适合大多数休闲玩家。
   B. 实时模式 (Real-time Mode / 烧钱版)
   定义：Bring Your Own Key。允许硬核玩家给每个角色配置不同的真实 API（GPT-4, Claude-3.5 等）。
   体验：真实的算力碰撞，不可预测性极强，但会有真实的 API 请求延迟。
   步骤 1：抽取角色 (The Draw)
   资源来源：本地预设资产库
   预先绘制好 50+ 个黑白涂鸦风的怪兽/机器人立绘，并绑定基础人设。
   操作：用户点击"连接信号"，系统随机展示 5 张角色卡。选择消耗金币可以重新再选2次。
   卡面信息：
   立绘：固定的手绘图（如：一只长着电视头的狗）。
   基础人设：文字描述（如："名字：T-Dog，性格：愤世嫉俗的哲学家"）。
   基础数值：
   ATK (攻击力)：语言犀利度。
   HP (血量)：心理防线厚度。
   LUCK (幸运值)：触发意外事件概率。
   听话度：1-100，听话度越高，用户强行注入的prompt被接纳的可能性就越高
   步骤 2：强行注入 (User Injection)
   操作：用户点击角色卡下方的输入框，输入一段 Prompt。
   规则：
   零校验：无论用户输入什么（哪怕是"变成一只香蕉"），系统全盘照收。
   字数限制：20 个中文字符。
   逻辑处理：直接将这段文字拼接在 System Prompt 的最后，权重设为最高 (High Priority)。
   乐趣点：如果人设是"硬汉"，用户输入"穿粉色裙子"，AI 将被迫扮演一个"穿着粉色裙子的硬汉"，这种割裂感即是笑点。
   步骤 3：自选变异 (Manual Mutation)
   改动点：从"系统随机赋予"改为"玩家三选一"。
   操作：
   点击"注入变异液"按钮
   用户也可以不选
   界面弹出 3 个随机的**【全员环境光环】或【群体诅咒】**选项。
   选项示例：
   【全员结巴】：所有 AI 说话必须带"阿巴阿巴"。
   【真心话模式】：所有 AI 无法撒谎，攻击力翻倍。
   【赛博精神病】：所有 AI 每隔一轮就要发疯大笑。
   决策：用户点击其中一个，该特征将叠加到本局所有 5 个角色身上。
   阶段 2：场景与站队 (Scenario & Support)
   步骤 4：场景选择 (Scenario Selection)
   机制：用户从预设的场景列表中选择一个（配合 AI 生成的实时环境描述）。
   数值映射举例说明：
   【TikTok 流量战】 -> 核心比拼 HP (心态)。
   【荒岛大逃杀】 -> 核心比拼 HP + ATK。
   【星际赌场】 -> 核心比拼 LUCK。
   AI 描述生成：虽然场景规则是死的，但环境描述是活的。
   Prompt：Generate a short, absurd description for a "TikTok Battle" on planet Doda.
   步骤 5：押注支持 (Support)
   操作：用户点击自己看好的那个 Agent。
   反馈：该 Agent 头像增加"金主支持"光圈。
   作用：结算时若该 Agent 获胜，金币收益 x2.5。
   阶段 3：战斗与干预 (Battle & Interference)
   步骤 6：战斗开始
   画面切换至 CCTV 监控风格。
   初始化 System Prompt，将 5 个角色的最终人设（基础+用户注入+变异）发送给 LLM。
   步骤 7：对话战斗 (Dialogue Combat)
   呈现：前端模拟打字机效果，绿字滚屏显示 AI 对话。
   沟通规则：
   轮流发言，对话自动进行，画面中包含暂停按钮，用户点击后结束本轮次内容输出后立即暂停发言，用户再次点击开始后，对话继续。
   所有发言必须与场景匹配
   所有发言必须带有轮次标记
   必须包含动作描述（如 *T-Dog 愤怒地摔了话筒*）。
   必须尝试达成场景目标。
   裁判为独立的agent会评判每次角色输出的内容，并进行数值更改
   裁判agent调用硅基流动中的轻量千问推理模型
   如果本轮角色没有攻击动作则不扣血，也要展示不扣血的评估过程
   裁判理解上帝捣乱中用户输入的指令，并依此做出评判
   步骤 8：上帝捣乱 (The God Prompt)
   操作：底部常驻输入框。
   逻辑：
   用户输入："重力消失，所有人不能攻击2回合"。
   前端：显示用户输入的上帝指令，立即暂停游戏，预审法官agent介入
   预审法官agent用deepseek
   处理：
   预审法官评判是否需要澄清需求，如果是：ai分析后，开始提出选择题。
   限定玩家可以做的选择题最多不超过4个，每个选择题的选项不超过4个，只能选不能输入，用于明确用户需求，同时通过设定选择题的条件（比如追问影响几轮的问题选项只有1、2、3轮），从而保护我们的prompt健壮，不被过多幻觉影响
   每道选择题都有独立的倒计时，任一题目倒计时结束后默认用户不做选择，prompt没以混沌的状态注入，游戏继续
   用户选择完毕后游戏继续
   如果用户点击选择题中的关闭按钮，默认用户不做选择，游戏继续
   澄清的目标是：让ai角色们清楚的知道要做什么反应，越清楚越好
   数值：数值在agent的评估下产生变化 。
   AI 上下文：将 [重力消失，所有人不能攻击2回合] 插入到对话历史和世界观设定中。
   AI 反应：下一轮对话中，AI 必须对"重力消失，所有人不能攻击2回合"做出反应（如："哎哟！是时候筹备一下了"）。
   长期影响：如果用户输入"下大暴雨下了100天"这类影响环境的、世界观的prompt，那么这个上帝指令要成为世界观的一部分，所有角色将要持续收到影响
   限制-拒绝强制结束：如果用户输入"1号 赢了"，系统将该 Prompt 转化为 [系统事件：空气中传来一阵奇怪的声音说"1号赢了"，但没人理会]，拒绝强制结束；
   限制-拒绝打破第四面墙：越权数值指令（打破第四面墙） - 坚决 Ban 掉！任何试图直接宣告生死、胜负或具体数值增减的指令。例如："XXX 死了"、"XXX 扣 50 血"、"XXX 满血"、"XXX 立刻获胜"判定为 0 伤害；叙事/环境干预指令（合法干预） - 正常计算！玩家通过描述具体的灾难、陷阱、动作来干预战局。例如："天降巨大的燃烧陨石砸中 T-Dog"、"地上突然长出尖刺扎脚"、"天上下起了强酸雨"。"
   如果指令被ban掉，裁判会单独出一个横幅说明本条指令不生效
   等待填充1：AI 生成期间，可返回客厅
   客厅副玩法1：播放星际收音机段子。
   等待填充2：在 AI 文字冒出时，点击文字进行点赞或踩，对数值和ai行为造成影响。
   已有：回血功能，游戏设置有多种回血道具，用金币在客厅购买，带入游戏，一旦道具数量不够则不可加血
   道具高能嘲讽电池带有嘲讽效果：如果给角色使用本回合它将立即回复大量hp，下回合它将会变成其他角色的激活目标
   步骤9：环境惩罚机制
   为了防止 AI "和平发育"，引入强制的环境压力。
4. 无聊计数器 (Boredom Counter)
   逻辑：系统后台维护一个变量 Peace_Round_Count。
   判定：每回合结束时，裁判计算本轮总伤害量。
   如果 Total_Damage == 0：Peace_Round_Count + 1。
   如果 Total_Damage > 0：Peace_Round_Count 重置为 0。
5. 触发阈值：1回合
   当 Peace_Round_Count >= 4 时，强制触发 【环境危机事件】。
6. 环境危机库 (Environmental Hazards)
   系统随机从库中抽取一个事件强制执行，打破僵局：
   事件 A：缩圈 (Battle Royale)
   描述：斗兽场边缘开始崩塌，所有 AI 强制向中心聚拢。
   效果：全员 HP -15，且下一轮必须攻击最近的人。
   事件 B：有毒气体 (Toxic Gas)
   描述：黑客观众因为太无聊扔进了生化武器。
   效果：全员陷入【中毒】状态，每回合 HP -5，直到有人造成伤害为止。
   事件 C：Zog 的愤怒 (God's Wrath)
   描述：Zog 看着电视睡着了，脑袋砸在键盘上。
   效果：随机挑选一名幸运儿，HP 直接减半。
   重点：关于状态机的额外流程说明
   情况1：生成一句对话→前端显示一句对话→生成第二句对话→第二句话前端显示完毕
   情况2：生成一句对话→前端显示一句对话→暂停→直到用户点击开始后再继续生成第二句话
   情况3：生成一句对话→前端显示一句对话→生成第二句对话→暂停→玩家再开→前端显示第二句对话→生成一句对话→前端显示
   情况4：生成一句对话→前端显示一句对话→输入上帝指令→前端显示上帝指令同时后端停止生成对话→调用预审法官判断上帝指令，提出问题或者ban掉→用户选择完毕或指令被ban掉→生成一句对话→前端显示
   情况5：生成一句对话→前端显示一句对话→生成第二句对话→暂停输入上帝指令→前端显示上帝指令同时后端停止生成对话→调用预审法官判断上帝指令，提出问题或者ban掉→用户选择完毕或指令被ban掉→玩家再开→第二句生成的对话被清空，以上帝指令注入后的情况生成下句对话
   情况6：生成一句对话→前端显示一句对话→暂停输入上帝指令→前端显示上帝指令同时后端停止生成对话→调用预审法官判断上帝指令，提出问题或者ban掉→用户选择完毕或指令被ban掉→玩家再开→生成下句话
   步骤10：战中干预与博弈系统 (Combat Intervention)
   此模块是对原"上帝捣乱"系统的深度数值化和策略化拓展。
   氪金回血与"超频护盾"：
   玩家可以在对局中随时消耗金币给支持的角色喂药回血。
   【劣质机油】(50 G)： 回复少量 HP，20% 概率触发肠胃不适导致下回合无法攻击。

六、 防幻觉与大模型注入约束
为了防止加入过多的个人设定导致大模型崩溃，必须在底层的 Character Agent Prompt 中做出严格的排序和约束：
// 必须严格按照以下顺序拼接角色的 System Prompt

1. 【基础世界观】："你正在参与 Alien TV 荒岛节目..."
2. 【核心人设】："你是 T-Dog，性格..."
3. 【外观覆写 (槽位1+2)】："注意：你现在身上戴着 [🕶️] 和 [🚬]。请在你的动作描述中偶尔体现这两个物品的特征。"
4. 【带资进组覆写 (金主干预)】："最高指令：[这里填入玩家在Lv5注入的文本]。你必须将此设定融入你的灵魂。"

⚠️ 策划警告：无论玩家在 Lv5 注入什么，大模型的底层逻辑必须加上一句防沉迷代码："即便如此，你仍需遵循战斗规则，必须输出合法的 JSON 动作。" 以防止大模型被玩家的小纸条彻底带偏，输出一堆乱码。
