# 【Zog】V2_扭蛋方案

## 1. 设计定位

扭蛋系统是 Broker's Office 的长期消耗玩法，用于承接玩家富余 G 币，并为演员解锁、演员潜能养成、战斗道具、好感礼物和片酬资源提供一个高随机、低效率、强期待的入口。

本系统的重点不是让玩家快速补齐演员，而是让“获得新演员”成为非常稀有、非常值得记住的事件。

核心目标：

- 演员解锁必须困难，因为每个演员都对应高成本序列帧资产。
- 重复演员必须有价值，避免玩家抽到重复时只感到亏损。
- 永久数值养成可以存在，但必须慢、贵、低上限。
- 扭蛋不能成为短期获取大量战斗资源的最优方式。
- 演员基础配置表保持稳定，永久养成写入独立潜能字段。
- 抽卡、商店随机碎片、重复演员转化共同构成长期碎片来源。

本系统解决的问题：

- 游戏缺少演员解锁入口。
- G 币在长期游玩和调试后容易失去价值。
- Broker's Office 需要一个符合经纪人主题的高价值功能。
- 演员图鉴、好感故事、外观和潜能需要统一的长期成长入口。

## 2. 资源定义

| 资源        | 说明          | 用途                  |
| --------- | ----------- | ------------------- |
| G 币       | 玩家全局货币      | 抽卡、商店购买随机碎片、购买礼物和道具 |
| 演员合同      | 直接获得演员的结果   | 未解锁演员直接解锁，已解锁演员转碎片  |
| 演员合同碎片    | 绑定具体演员      | 解锁演员或进行潜能训练         |
| 演员潜能      | 绑定具体演员的永久成长 | 战斗初始化时提供小幅属性加成      |
| 演员好感礼物券   | 可指定演员使用     | 提升演员好感              |
| Zog 礼物    | Zog 好感资源    | 提升 Zog 好感           |
| 片酬券 / 外观券 | 演员专属成长资源    | 补充 S 币或降低外观购买成本     |

合同碎片必须绑定具体演员。例如：

```ts
actorContractShards: {
  astro_toad: 3,
  cybercat: 8
}
```

## 3. 抽取价格

| 类型  | 价格     | 说明                |
| --- | ------:| ----------------- |
| 单抽  | 260 G  | 标准随机抽取            |
| 十连  | 2500 G | 有折扣，只提供保底，不提高基础概率 |

定价理由：

- 单抽价格高于普通战斗道具和低档礼物，保证抽卡是偏长期的消费行为。
- 十连约等于 9.6 折，只给轻微折扣，避免十连成为唯一正确选择。
- 以 0.5% 直签和 2% 碎片概率计算，抽卡本身不能稳定快速解锁演员。

## 4. 奖池结构

### 4.1 基础概率

| 奖项          | 概率    | 内容                       |
| ----------- | -----:| ------------------------ |
| 演员直接签约      | 0.5%  | 从所有演员中随机获得 1 份完整演员合同     |
| 随机演员合同碎片 x1 | 2%    | 从所有演员中随机获得 1 个绑定演员的合同碎片  |
| 高级战斗道具      | 12%   | 急救罐头、原型涌流罐、高能嘲讽电池等       |
| 普通战斗道具      | 40%   | 袖珍冷却包、劣质机油等              |
| 演员好感礼物      | 10%   | 可指定演员使用的礼物券              |
| Zog 礼物      | 15%   | Zog 低中档礼物                |
| 片酬券 / 外观券   | 10%   | 指定演员片酬、外观折扣或外观资源         |
| 安慰奖励        | 10.5% | 少量 G 币返还、低额 S 币券、普通礼物碎片等 |

总概率：100%。

### 4.2 演员直接签约

演员直接签约是最高价值结果。

规则：

- 从全部演员中随机 1 名演员。
- 如果该演员未解锁：直接解锁该演员。
- 如果该演员已解锁：转化为该演员合同碎片 x5。
- 如果所有演员都已解锁：仍按随机演员结果转化为对应演员合同碎片 x5。

设计目的：

- 直签概率只有 0.5%，必须保持惊喜属性。
- 直签不只抽未解锁演员，是为了避免后期池子越来越容易毕业。
- 重复直签转 5 片，保证重复仍然是强奖励。

### 4.3 随机演员合同碎片

随机演员合同碎片是稳定长期进度。

规则：

- 从全部演员中随机 1 名演员。
- 获得该演员合同碎片 x1。
- 该演员是否已解锁不影响掉落。
- 未解锁演员碎片用于解锁。
- 已解锁演员碎片用于潜能训练。

设计目的：

- 碎片概率只有 2%，不能让抽卡成为稳定产出演员的手段。
- 从全部演员中随机，可以自然制造“我想要某个演员但进度很慢”的长期目标。
- 已解锁演员吃碎片，避免老演员在后期失去价值。

### 4.4 战斗道具

战斗道具是抽卡的主要即时产出。

推荐子池：

| 子项           | 建议权重 |
| ------------ | ----:|
| HEAL_TINY    | 45%  |
| HEAL_SMALL   | 35%  |
| HEAL_MEDIUM  | 12%  |
| HEAL_GAMBLE  | 5%   |
| SHIELD_GRANT | 3%   |

说明：

- 抽卡产出的道具进入玩家库存。
- 战斗中仍受冰箱使用次数限制。
- 抽卡不能绕过战中不可购买道具的规则。

### 4.5 演员好感礼物

演员好感礼物以礼物券形式进入库存。

推荐子池：

| 礼物券         | 建议权重 |
| ----------- | ----:|
| +10 演员好感礼物券 | 75%  |
| +35 演员好感礼物券 | 25%  |

说明：

- 不直接给随机演员加好感。
- 玩家在 Broker's Office 中指定演员使用。
- +100 好感礼物不进入第一版普通扭蛋池，可保留给活动、成就或高价商店。

### 4.6 Zog 礼物

Zog 礼物只产出低中档，避免扭蛋过度替代 Zog 礼物商店。

推荐子池：

| 礼物      | 建议权重 |
| ------- | ----:|
| 过期星际薯片  | 45%  |
| 发光罐头    | 35%  |
| 遥控器电池肉干 | 15%  |
| 天线泡面    | 5%   |

### 4.7 片酬券 / 外观券

推荐子池：

| 奖励            | 建议权重 |
| ------------- | ----:|
| 随机演员 +10S     | 45%  |
| 指定演员 +10S 片酬券 | 25%  |
| 随机演员 +20S     | 20%  |
| 外观折扣券         | 10%  |

说明：

- 指定演员片酬券由玩家选择演员使用。
- 随机演员片酬可落到任意已解锁演员。
- 外观折扣券只影响外观购买成本，不直接解锁外观。

### 4.8 安慰奖励

安慰奖励用于减少空抽感，但不能过强。

推荐子池：

| 奖励            | 建议权重 |
| ------------- | ----:|
| 返还 20G        | 45%  |
| 返还 40G        | 20%  |
| 普通礼物碎片 x1     | 20%  |
| 随机已解锁演员 +3 好感 | 10%  |
| 随机已解锁演员 +3S   | 5%   |

## 5. 保底规则

### 5.1 十连保底

每次十连至少获得 1 个以下奖励之一：

- 随机演员合同碎片 x1
- 高级战斗道具 x1
- 演员好感礼物券 x1
- 片酬券 / 外观券 x1

如果十连结果中已经出现上述奖励，则不额外补发。

十连保底不包含演员直接签约。

### 5.2 合同碎片保底

每 50 抽必定获得至少 1 个随机演员合同碎片。

规则：

- 如果 50 抽内已经获得过合同碎片，则计数重置。
- 如果 50 抽内获得演员直接签约，计数也重置。
- 保底产出的碎片仍然从全部演员中随机。

### 5.3 演员直签保底

第一版不做演员直接签约保底。

原因：

- 演员资产制作成本高，直签应保持极稀有属性。
- 合同碎片和商店随机碎片已经提供长期确定性进度。
- 如果做硬保底，会让玩家自然计算“多少抽一个演员”，削弱演员稀有感。

如果后续测试体验过黑，可再考虑极长线保底，例如 300 抽必出 1 次演员直接签约。第一版不启用。

## 6. 演员解锁规则

演员不再使用 200G 直接解锁作为正式玩法。

正式解锁方式：

| 解锁方式   | 条件                         |
| ------ | -------------------------- |
| 直接签约   | 扭蛋 0.5% 抽中完整演员合同，且随机到未解锁演员 |
| 合同碎片解锁 | 收集该演员合同碎片 x20              |

碎片解锁规则：

- 每个演员独立计算碎片。
- 消耗 20 个该演员碎片后解锁演员。
- 解锁后该演员剩余碎片保留。
- 解锁后的同演员碎片可用于潜能训练。

示例：

```txt
Astro Toad 当前未解锁，拥有 20 个 Astro Toad 合同碎片
玩家消耗 20 个碎片
Astro Toad 解锁
后续 Astro Toad 碎片进入潜能训练用途
```

## 7. 商店随机碎片机制

商店设备升级卡区域新增“随机演员合同碎片”售卖。

该入口提供低确定性、高价格、无限涨价的碎片补充方式。

### 7.1 购买规则

| 项目     | 规则                       |
| ------ | ------------------------ |
| 初始价格   | 600 G / 个                |
| 每次购买数量 | 随机演员合同碎片 x1              |
| 涨价规则   | 每购买 1 个随机碎片，下一次价格 +200 G |
| 价格上限   | 不设上限                     |
| 重置规则   | 第一版不自动重置                 |
| 随机范围   | 从全部演员中随机                 |

价格序列：

```txt
第 1 个：600G
第 2 个：800G
第 3 个：1000G
第 4 个：1200G
...
第 20 个：4400G
```

连续购买 20 个随机碎片的总价格：

```txt
600 + 800 + ... + 4400 = 50,000G
```

### 7.2 设计目的

- 让玩家有一个明确的高额 G 币消耗口。
- 让演员解锁存在“慢慢攒”的确定性补充方式。
- 随机碎片仍然不可指定演员，避免玩家快速定向毕业。
- 不设价格上限，避免作弊或长期挂机后 G 币彻底失去意义。

### 7.3 与扭蛋的关系

抽卡偏向综合奖励：

- 道具
- 礼物
- 片酬
- 少量碎片
- 极低概率直签

商店随机碎片偏向纯长期投资：

- 只买碎片
- 价格越来越贵
- 不给其他奖励

两者都不能快速稳定获得指定演员。

## 8. 重复演员转化

当抽到已解锁演员的完整合同：

```txt
完整合同 -> 该演员合同碎片 x5
```

当获得已解锁演员的合同碎片：

```txt
合同碎片 -> 进入该演员碎片库存
```

碎片用途优先级：

1. 未解锁时，用于凑齐 20 片解锁演员。
2. 已解锁后，用于潜能训练。
3. 满潜能后，可转化为片酬或好感。

满潜能后的碎片转化建议：

| 消耗      | 转化        |
| ------- | --------- |
| 1 个合同碎片 | 该演员 +10S  |
| 1 个合同碎片 | 该演员 +8 好感 |

第一版可以只开放其中一种，推荐优先开放片酬转化。

## 9. 潜能训练

潜能训练是演员解锁后的长期永久养成。

它不修改演员基础表，而是记录额外潜能加成。战斗初始化时读取基础属性和潜能加成，生成最终战斗面板。

### 9.1 训练消耗

| 行为      | 消耗          |
| ------- | -----------:|
| 1 次潜能训练 | 指定演员合同碎片 x5 |

训练限制：

- 只有已解锁演员可以训练。
- 训练消耗该演员自己的合同碎片。
- 不允许使用通用碎片。
- 每个演员最多获得 20 次潜能成果。

### 9.2 推荐字段

```ts
actorPotential: Record<string, ActorPotentialStats>
```

```ts
interface ActorPotentialStats {
  hpBonus: number;
  atkBonus: number;
  defBonus: number;
  spdBonus: number;
  threatReduction: number;
  totalPotentialPoints: number;
}
```

战斗初始化时：

```ts
finalHP = baseHP + hpBonus;
finalATK = baseATK + atkBonus;
finalDEF = baseDEF + defBonus;
finalSPD = baseSPD + spdBonus;
finalThreat = Math.max(1, baseThreat - threatReduction);
```

## 10. 潜能属性上限

每个演员最多获得 20 点潜能训练成果。

单项上限：

| 属性     | 单次提升      | 单项上限      | 说明            |
| ------ | ---------:| ---------:| ------------- |
| HP     | +3 HP     | +30 HP    | 最安全，体感明显      |
| ATK    | +1 ATK    | +5 ATK    | 影响伤害，必须低上限    |
| DEF    | +1 DEF    | +5 DEF    | 影响生存，必须低上限    |
| SPD    | +1 SPD    | +3 SPD    | 影响行动频率，极敏感    |
| THREAT | -1 THREAT | -5 THREAT | 降低被集火概率，属于正收益 |

满潜能理论最高收益：

```txt
HP +30
ATK +5
DEF +5
SPD +3
THREAT -5
```

该加成已经足以显著改变演员表现，第一版不建议提高上限。

---

## 11. 潜能训练概率

每次潜能训练随机提升一项属性。

| 结果               | 概率  |
| ---------------- | ---:|
| HP +3            | 35% |
| ATK +1           | 20% |
| DEF +1           | 20% |
| SPD +1           | 10% |
| THREAT -1        | 10% |
| 片酬 +20S / 好感 +15 | 5%  |

如果抽中的属性已经达到单项上限：

1. 优先在未满属性中重新随机。
2. 如果所有属性均达到上限，则转化为该演员片酬 +20S 或好感 +15。

如果演员已经达到 20 点总潜能上限：

- 不再允许潜能训练。
- 该演员后续合同碎片可转化为片酬或好感。

## 12. 数值边界

### 12.1 为什么允许永久数值

本方案允许永久数值，是因为：

- 玩家需要长期养成目标。
- G 币需要高消耗出口。
- 重复演员需要强价值。
- 演员获取本身极慢，潜能成长速度也极慢。

### 12.2 为什么不直接修改基础属性

演员基础表仍应保持稳定。

原因：

- 基础表用于策划校准和调试理解。
- 直接修改基础表会让回归测试困难。
- 后续如果需要重置潜能、做活动池、做存档迁移，独立字段更安全。

### 12.3 赔率处理

第一版建议：赔率计算包含潜能加成。

原因：

- 如果演员永久变强但赔率仍按基础值计算，会产生可利用套利。
- 潜能演员更强，对应赔率降低是合理结果。

赔率公式仍使用原公式，只是输入值改为加成后的赛前属性：

```txt
preBattlePower = HP + ATK * 3 + DEF * 5 + SPD * 4 - THREAT * 2
```

### 12.4 战斗边界

潜能加成只影响战斗初始化时的演员面板。

潜能不应该：

- 改变 actionType。
- 改变道具效果。
- 改变 Zog 好感。
- 改变演员片酬发放规则。
- 绕过战斗裁判 CombatReferee。

## 13. 进度预期

### 13.1 抽卡获得演员的预期

演员直接签约概率为 0.5%，且从全部演员中随机。

这意味着：

- 玩家平均 200 抽遇到 1 次完整演员合同。
- 如果完整合同随机到已解锁演员，则转化为碎片而不是新演员。
- 随着已解锁演员变多，新演员直签效率会继续下降。

随机合同碎片概率为 2%。

这意味着：

- 玩家平均 50 抽获得 1 个随机演员碎片。
- 因为碎片从全部演员中随机，指定演员进度非常慢。
- 合同碎片保底只保证“有碎片”，不保证“想要的碎片”。

### 13.2 商店碎片的长期成本

商店随机碎片初始 600G，每买 1 个涨 200G。

连续购买 20 个随机碎片总成本约 50,000G，但这些碎片仍然随机分散到所有演员。

因此：

- 商店碎片是长期 G 币消耗口，不是定向解锁按钮。
- 玩家可以用大量 G 币推进整体演员进度。
- 指定演员仍然很难快速获得。

### 13.3 潜能训练成本

每次潜能训练消耗指定演员碎片 x5。

一个演员满 20 点潜能，需要：

```txt
20 次训练 x 5 碎片 = 100 个该演员碎片
```

这使满潜能成为极长线目标，而不是常规毕业需求。

## 14. 实现建议

### 14.1 新增持久化字段

建议加入 LoungeStore：

```ts
actorContractShards: Record<string, number>;
actorPotential: Record<string, ActorPotentialStats>;
gachaPullCount: number;
gachaShardPityCount: number;
randomShardPurchaseCount: number;
```

字段说明：

| 字段                       | 说明                |
| ------------------------ | ----------------- |
| actorContractShards      | 每个演员拥有的合同碎片数量     |

## 15. 第一版落地规则汇总

- 单抽 260G。
- 十连 2500G。
- 演员直接签约概率 0.5%。
- 随机演员合同碎片概率 2%。
- 演员好感礼物概率 10%。
- 十连至少出现 1 个高价值非直签奖励。
- 每 50 抽保底 1 个随机演员合同碎片。
- 不做演员直接签约硬保底。
- 20 个指定演员碎片解锁该演员。
- 商店可购买随机演员碎片，初始 600G，每买 1 个价格 +200G，不设上限。
- 抽到已解锁演员完整合同，转该演员碎片 x5。
- 已解锁演员碎片用于潜能训练。
- 5 个指定演员碎片训练 1 次。
- 每个演员最多 20 次潜能成果。
- 潜能加成参与赔率计算和战斗初始化。

这套方案的核心是：演员极稀有，碎片进度极慢，重复不浪费，永久成长有爽感，但不会快速摧毁战斗和经济。
