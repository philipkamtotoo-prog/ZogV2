# 【Zog】V2 角色序列帧视频提示词

## 使用说明

本文档用于用 AI 视频生成角色动作，再抽帧制作游戏序列帧。每个角色都按当前原画形态写提示词。`eliminated` 不做视频，改为单张 PNG 贴图。

原画目录：

```text
E:\ZogV2\public\角色原画
```

建议每次生成动作视频时，把对应角色原画作为参考图输入，并在提示词中强调“严格保持参考图角色设计”。如果角色有三视图，优先使用 3/4 侧面视图作为动作参考；如果工具支持多图参考，可以同时输入三视图图。

## 全局视频要求

所有动作视频默认使用以下要求：

```text
使用输入原画作为唯一角色设计参考，严格保持角色的身体比例、颜色、五官、配件、发光部件、轮廓和材质特征。
生成 2D 卡通游戏角色动作视频，用于后续抽帧制作序列帧。
固定镜头，角色全身完整入镜，纯色背景，无地面，无阴影，无文字，无 UI。
动作清楚、节奏夸张、轮廓稳定，适合小尺寸游戏舞台播放。
角色始终保持同一个 3/4 侧面朝右方向，除非提示词明确要求轻微转身。
动作开始和结束尽量回到相近姿势，方便后续循环或剪辑。
```

## 全局视频反向提示词

每条视频提示词都使用以下反向提示词：

```text
不要改变角色设计，不要换颜色，不要改变比例，不要改变配件位置，不要多长出肢体，不要丢失尾巴、耳朵、天线、项圈、背包、帽子、眼柄、账单等关键元素。
不要出现额外角色，不要出现背景场景，不要出现文字、水印、字幕、UI、镜头切换、镜头旋转、强透视、复杂光影、投影、地面、烟雾遮挡、爆炸遮挡、真实 3D 渲染、写实材质、过度模糊、运动残影过多。
不要让角色跑出画面，不要裁切头部或脚部，不要让动作导致轮廓大幅变形，不要让角色在动作中变成另一个形态。
```

## 全局 PNG 要求

`eliminated` 使用单张 PNG 贴图。建议生成纯色背景版本，后续抠图或转透明。

```text
使用输入原画作为唯一角色设计参考，生成单张 2D 卡通游戏角色出局贴图。
角色保持原设计、原配色、原轮廓，但表现为战斗出局、失去行动能力、信号断开或瘫倒状态。
纯色背景，无阴影，无地面，无文字，无 UI，无额外角色。
画面保留完整角色，留足边距，适合做透明 PNG 游戏贴图。
```

## 动作规格总表

| 动作名            | 类型  | 建议时长  | 用途                       |
| -------------- | --- | -----:| ------------------------ |
| `idle`         | 视频  | 2.0 秒 | 待机循环，战场常驻状态              |
| `basic_attack` | 视频  | 1.2 秒 | 造成伤害的通用攻击表现              |
| `show_action`  | 视频  | 1.5 秒 | 非纯攻击节目行动，如偷鸟、建巢、栽赃、嘲讽、安抚 |
| `hit`          | 视频  | 0.8 秒 | 受击反馈                     |
| `eliminated`   | PNG | 单图    | 出局贴图                     |

参考原画：

```text
E:\ZogV2\public\角色原画\tdog.png
```

角色锁定描述：

```text
T-Dog 是一只尖酸哲学外星狗。短腿、大头、深棕身体、浅棕嘴鼻和肚皮、半眯青色眼睛、额头第三眼、破损电视天线耳、低科技翻译项圈、黄色吊牌、信号球尾巴、身体补丁和少量外星斑点。
```

### idle 视频

时长：2.0 秒，循环。

```text
让 T-Dog 做待机循环动作：身体轻微呼吸起伏，半眯眼缓慢眨眼，第三眼偶尔半睁一下，破损天线耳轻轻抖动，尾巴末端的青色信号球微弱闪烁。整体姿态懒散、嘲讽、疲惫，像正在冷眼旁观节目事故。动作幅度小，角色始终站在原地。
```

反向提示词：

```text
使用全局视频反向提示词。额外避免：不要让 T-Dog 变成普通狗，不要让第三眼消失，不要让尾巴信号球变成普通尾巴，不要张嘴大笑，不要过度可爱卖萌。
```

### basic_attack 视频

时长：1.2 秒。

```text
让 T-Dog 发动一次毒舌声波攻击：它向前探身，半眯眼变得更尖锐，项圈亮起青色小屏，嘴边吐出短促的声波弧线，尾巴信号球同步闪一下。攻击后身体退回原位，表情仍然很嫌弃。
```

反向提示词：

```text
使用全局视频反向提示词。额外避免：不要加入真实文字台词，不要出现巨大能量炮，不要让声波遮住角色，不要让角色离开画面。
```

### show_action 视频

时长：1.5 秒。

```text
让 T-Dog 执行节目行动：第三眼亮起，天线耳接收信号，项圈像低科技广播器一样闪烁，它抬起一只前爪做出审判和甩锅的姿态，尾巴信号球发出两段小广播波纹。动作像在嘲讽、栽赃或发表哲学点评，不是直接攻击。
```

反向提示词：

```text
使用全局视频反向提示词。额外避免：不要出现文字标语，不要让它变成施法法师，不要出现复杂魔法阵。
```

### hit 视频

时长：0.8 秒。

```text
让 T-Dog 受击：身体短促后仰，耳朵天线晃歪，半眯眼短暂变成震惊表情，尾巴信号球闪烁短路两下，然后它迅速恢复成嫌弃脸。动作清楚但不要大幅位移。
```

反向提示词：

```text
使用全局视频反向提示词。额外避免：不要让角色倒地，不要血腥，不要让配件飞散消失。
```

### eliminated PNG

```text
生成 T-Dog 的出局 PNG 贴图：T-Dog 侧躺或趴倒，眼睛变成疲惫的半闭状态，第三眼关闭，天线耳一边歪掉，项圈屏幕暗下去，尾巴信号球只剩微弱蓝光。保持可爱荒诞，不血腥，完整角色，纯色背景，无阴影，无文字，无 UI。
```

## 制作建议

1. 先用每个角色的 `idle` 视频测试风格稳定性。只有 idle 稳定，后面的攻击和受击才值得继续生成。
2. 每个动作单独生成，不要一次生成多个动作。
3. 对 AI 视频来说，`hit` 最容易变形，建议多生成几版，只取轮廓最稳的版本抽帧。
4. `show_action` 是 Zog 的关键动作，不要改回传统 `skill_cast`。它承载的是节目行动，不是技能系统。
5. `eliminated` 做成 PNG 是合理的，能节省大量动画工作量。后续可用程序叠加变灰、闪烁、缩放、信号断开等效果。
