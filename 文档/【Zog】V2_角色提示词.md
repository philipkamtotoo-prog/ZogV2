# 【Zog】V2 角色提示词

## 使用目的

本文档用于生成 Zog V2 战斗演员角色图、三视图、动作视频和后续序列帧参考。当前美术方向优先服务于固定战斗舞台：角色需要在小尺寸下可读、轮廓明确、动作容易识别，并保持低科技外星电视节目的荒诞感。

角色不是写实怪物，也不是普通宠物。每个角色都应该有一个清楚的普通生物/物体基底，再叠加 2 到 3 个强外星识别点。

## 通用角色提示词

```text
生成一个 Zog V2 战斗演员角色，适合制作 2D 游戏序列帧动画。

角色需要是可爱、荒诞、低科技外星电视节目风格的战斗演员，不是写实生物，不是普通宠物，不是精致商业吉祥物。

画风要求：
简洁 2D 卡通游戏角色，粗外轮廓，少量内部线条，扁平色块，轮廓清楚，适合小尺寸显示，适合后续做序列帧动画。

构图要求：
完整全身，居中，留足边距，纯色背景，无阴影，无地面，无文字，无 UI。角色的头、身体、四肢、尾巴、耳朵、关键配件需要清楚可见。

设计要求：
角色必须有清楚的大剪影，远看也能认出是谁。每个角色保留 2 到 3 个强识别外星元素，不要堆太多细碎装饰。颜色控制在 5 到 6 个主色以内。
```

## 三视图通用提示词

```text
生成同一个角色的三视图参考图，三种视角放在同一张图上。

从左到右依次为：正面、右向 3/4 侧面、背面。

三视图必须保持完全一致的身体比例、颜色、外星特征、服装配件、尾巴形态和关键装饰。不要添加文字标签。纯色背景，无阴影，无地面，无 UI。
```

## 动作视频通用提示词

```text
生成一个短循环角色动作视频，用于提取 2D 游戏序列帧。

角色保持固定设计、固定配色、固定比例，纯色背景，镜头固定，角色始终完整入镜，不要旋转镜头，不要切镜头，不要出现额外角色，不要出现文字或 UI。

动作需要清楚、节奏夸张、适合做游戏序列帧。动作开始和结束尽量回到相同或相近姿势，方便循环。
```

## 序列帧动画种类统计

### 全角色通用动作

首发建议所有角色都做以下 8 类动作，够支撑当前战斗表现：

1. `idle` 待机循环：角色呼吸、轻微晃动、眼睛或发光点小变化。
2. `enter` 入场：从电视信号/舞台边缘出现，落到站位。
3. `move` 小位移：短距离挪动、冲刺准备或换站位。
4. `basic_attack` 普通攻击：通用伤害动作，可覆盖多数 `DAMAGE` 事件。
5. `show_action` 节目行动：只行动、不一定攻击的夸张表演动作，用于贿赂渡渡鸟、建巢、栽赃、控场、表态、制造节目效果等非纯攻击 actionType。
6. `hit` 受击：被打、闪白、后仰、压扁或短暂故障。
7. `stun_or_fail` 失败/眩晕/信号干扰：用于 fallback、肠胃不适、行动失败、节目事故。
8. `eliminated` 出局：倒下、变灰、信号断开、沉入地面或被节目组拖走。

### 节目机制动作

这 5 类不一定每个角色都要第一批全做，但它们和当前 actionType 很贴合：

1. `bribe_dodos` 贿赂渡渡鸟：拿出食物、发出诱惑信号、吸引鸟群。
2. `steal_dodos` 偷渡渡鸟：抓、吸、骗、拖走鸟群。
3. `build_nest` 建假巢：搭建、召唤、展开巢区装置。
4. `frame_target` 栽赃目标：指认、广播污名、甩锅。
5. `stampede_or_scare` 惊吓/暴动：制造大动静，引发鸟群冲撞。
