# 【Zog】V2 角色提示词

## 使用目的

本文档用于生成 Zog V2 战斗演员的角色原画、三视图、动作视频和后续序列帧参考。当前美术优先服务于固定战斗舞台：小尺寸可读、轮廓明确、动作容易识别，并保持低科技外星电视节目的荒诞感。

角色不是写实怪物，也不是普通宠物。每个角色都应该有一个清晰的普通生物或物体基底，再叠加 2 到 3 个强外星识别点。

## 通用角色提示词

```text
生成一个 Zog V2 战斗演员角色，适合制作 2D 游戏序列帧动画。

角色需要是可爱、荒诞、低科技外星电视节目风格的战斗演员，不是写实生物，不是普通宠物，不是精致商业吉祥物。

画风要求：简洁 2D 卡通游戏角色，粗外轮廓，所有元素都带清晰描边，少量内部线条，扁平实体色块，轮廓清楚，适合小尺寸显示，适合后续做序列帧动画。

重要限制：不要依赖透明层。角色本体、光效、烟尘、信号波、能量、泡泡、火花、故障块、声波、星图线、霓虹光都必须画成“有描边的实体色块”或“有描边的贴纸状图形”。不要半透明渐变，不要羽化光晕，不要透明烟雾，不要柔边粒子。

构图要求：完整全身，居中，留足边距，纯色背景，无阴影，无地面，无文字，无 UI。角色的头、身体、四肢、尾巴、耳朵、关键配件必须清晰可见。

设计要求：角色必须有清晰的大剪影，远看也能认出是谁。每个角色保留 2 到 3 个强识别外星元素，不要堆太多细碎装饰。颜色控制在 5 到 6 个主色以内。
```

## 三视图通用提示词

```text
生成同一个角色的三视图参考图，三种视角放在同一张图上。

从左到右依次为：正面、右向 3/4 侧面、背面。

三视图必须保持完全一致的身体比例、颜色、外星特征、服装配件、尾巴形态和关键装饰。所有角色线条、道具、特效装饰都使用实体色块加清晰描边，不使用透明层或半透明光效。不要添加文字标签。纯色背景，无阴影，无地面，无 UI。
```

## 动作视频通用提示词

```text
生成一个短循环角色动作视频，用于提取 2D 游戏序列帧。

角色保持固定设计、固定配色、固定比例，纯色背景，镜头固定，角色始终完整入镜，不要旋转镜头，不要切镜头，不要出现额外角色，不要出现文字或 UI。

所有角色本体、特效和道具都必须是实体色块加粗描边。能量、霓虹、烟尘、火花、泡泡、声波、故障块、光圈、星图线、数据残影都画成有描边的贴纸状元素，不要透明层，不要半透明渐变，不要柔边光晕，不要真实烟雾。

动作需要清楚、节奏夸张、适合做游戏序列帧。动作开始和结束尽量回到相同或相近姿势，方便循环或剪辑。
```

## 序列帧动画种类定稿

首发建议所有角色都做以下 6 类资产：

1. `enter` 炫酷出场：角色从宇宙电视信号、舞台边缘、道具拟态或自身设定里登场，落到站位。
2. `idle` 待机循环：角色呼吸、轻微晃动、眼睛或发光点小变化。
3. `basic_attack` 普通攻击：通用伤害动作，覆盖多数 `DAMAGE` 事件。
4. `show_action` 节目行动：只行动、不一定攻击，用于偷鸟、建巢、栽赃、嘲讽、安抚、制造节目效果。
5. `hit` 受击：被打、闪白、后仰、压扁或短暂故障。
6. `eliminated` 出局 PNG：不做视频，做单张贴图，由程序负责闪烁、缩放、变灰或信号断开。

不使用 `skill_cast`。Zog 的战斗目前不是技能制，`show_action` 更贴近节目行动和 AI 行为表现。
