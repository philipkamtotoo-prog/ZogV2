当前代码已经完成过一轮数值对齐：战斗基础数值、演员表、场景初始值、伤害公式、FinalScore、赔率、挂机收益、乞讨收益、设备升级、演员片酬和主要道具效果都已基本按当前代码落地。

## 已对齐的重点

| 系统 | 当前实机状态 |
| --- | --- |
| 场景初始值 | `totalDodos=100`、`wildDodos=100`、演员 `dodoTrust=10`，`DODO_ALERT` 变异时开局为 7 |
| 首发演员表 | `DEFAULT_ROSTER` 已含 10 名演员，基础 HP/ATK/DEF/SPD/THREAT 与当前数值表一致 |
| 伤害公式 | `max(0, ATK * actionPower - DEF) * random(0.85..1.15)`，结果 clamp 到 `1..35` |
| 行动表 | `ACTION_DEFS` 已包含当前 10 个 actionType，`CLAIM_NEST_AREA` 已实现目标 `nestInfluence -5` |
| FinalScore | `HP + dodosControlled*2 + dodoTrust + nestInfluence*1.5` |
| MVP | 以 `totalDamageDealt` 最高判定，并列时排名更高者优先 |
| 赔率 | 按 `preBattlePower = HP + ATK*3 + DEF*5 + SPD*4 - THREAT*2` 排名给固定赔率 |
| 下注范围 | 50G 到 500G，整数 |
| 挂机收益 | 按 Zog 好感等级 2/3/4/5/7 G 每分钟 |
| 乞讨 | 冷却 10 分钟，按 Zog 好感等级给 20-40 到 120-180G |
| 设备升级 | 冰箱和键盘共用 Lv1-Lv5 升级树，成本 300/900/2500/7000G |
| 指令计费 | 预估/扣费基础为 20G/字，键盘限制 5/8/12/20/30 字 |
| 演员片酬 | 结算时按 60/35/20/10/0S + MVP 25S 入账 |
| 节目变异液 | 500G 购买，随机 3 选 1，已有 6 个 mutation |
| ReporterMemory | 已有事件扫描、阶段简报、状态扫描和 Display 映射骨架 |
| Pixi | 已接入 React Host + imperative Pixi runtime，Pixi 消费 `displayLog` 增量 |
