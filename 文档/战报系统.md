开发目标

把战报系统从：

战斗结束后扫 EventLog，临时拼一份文本

升级成：

战斗过程中持续沉淀节目素材，结算时组合成一份完整节目档案

三层结构：

EventLog
真实事实层，只记录发生了什么

ReporterMemory
节目素材层，记录哪些事实值得被报道、羞辱、总结、放大

BattleReport
最终展示层，把事实、素材、排名、账单、Zog 评价组合成可读战报
Phase R0：先修当前战报债务

优先级：P0，小修。

目标：

未注入退款不能在 finalizePendingCommands 和账单里重复加钱。
LLM 生成的最终战报要替换收藏里的 baseReport。
战报收藏要能保存 bill，而不是打开旧战报时塞空账单。
当前 report schema 加 version，避免之后 localStorage 旧数据炸。
完成标准：

结算金币只变化一次。
当场看到的 LLM 战报，之后从收藏打开还是同一份。
旧战报没有 bill 时 UI 能降级显示。
Phase R1：定义 ReporterMemory 数据模型

优先级：P0。

新增核心字段建议：

interface ReporterMemoryEntry {
  memoryId: string;
  battleId: string;
  actorActionIndex: number;
  type:
    | 'STAGE_BRIEF'
    | 'HIGHLIGHT'
    | 'SHAME'
    | 'ACCIDENT'
    | 'PLAYER_INTERVENTION'
    | 'ITEM_DRAMA'
    | 'MUTATION_DRAMA'
    | 'PROMPT_INJECTION'
    | 'ZOG_NOTE';

  title: string;
  text: string;
  actorIds: string[];
  eventIds: string[];
  severity: 1 | 2 | 3 | 4 | 5;
  tags: string[];
  source: 'SYSTEM' | 'LLM';
  createdAt: number;
}
BattleState 增加：

reporterMemory: ReporterMemoryEntry[];
reporterCursorActionIndex: number;
规则：

EventLog 只记事实。
ReporterMemory 可以有节目化文本，但必须引用 eventIds。
没有对应事件，就不能进 ReporterMemory。
LLM 只能改写表达，不能新增事实。
Phase R2：实现 ReporterMemoryCollector

优先级：P0。

新增模块建议：

src/features/reports/reporterMemory.ts
src/features/reports/reporterMemoryCollector.ts
src/features/reports/reporterMemoryRules.ts
它负责从 EventLog 里提取节目素材。

触发规则：

每次 actor action commit 后扫描新增 events。
每 5 或 10 个 action 生成一次 STAGE_BRIEF。
重大事件立即生成 memory。
第一版需要识别：

淘汰：ACCIDENT 或 HIGHLIGHT
大伤害：HIGHLIGHT
道具回血/救命：ITEM_DRAMA
玩家上帝指令：PLAYER_INTERVENTION
被羞辱/被陷害：SHAME
变异液效果：MUTATION_DRAMA
永久 Prompt 注入：PROMPT_INJECTION
低血量但没死：ACCIDENT 或 HIGHLIGHT
0 鸟 / 信任崩盘：SHAME
完成标准：

一场战斗结束后，reporterMemory.length > 0。
每条 memory 都能追溯到 eventIds。
不会每回合刷垃圾素材，只记录值得展示的点。
Phase R3：实时战地记者重做

优先级：P1。

现在实时播报是直接拿 recentLogs 调 LLM。后面改成：

EventLog -> ReporterMemoryCollector -> LiveReporter -> UI浮层
实时记者只播 ReporterMemory，不直接读散乱 event。

规则：

优先播 severity 高的 memory。
同一个 actor / 同一种事件短时间内不要重复播。
LLM 失败时用模板播报。
live report 要记录 sourceMemoryId，方便赛后回看。
LiveReport 建议改成：

interface LiveReport {
  liveReportId: string;
  sourceMemoryId: string;
  headline: string;
  summary: string;
  style: 'amused' | 'shocked' | 'concerned' | 'gleeful';
  createdAtActionIndex: number;
}
