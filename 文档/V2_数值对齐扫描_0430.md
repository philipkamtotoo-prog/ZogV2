## 建议施工顺序

### Phase A：数值底座（必须优先）

修复伤害引擎，让战斗数值与文档一致。此阶段不动经济/道具/片酬。

1. **演员表**：替换为文档10名演员及其数值（actorRoster.ts）
2. **场景初始值**：totalDodos=100, wildDodos=100, dodoTrust=10（initialState.ts）
3. **伤害公式**：修复为 `max(0, ATK * actionPower - DEF) * variance`，clamp到[1, 35]（combatReferee.ts + rng.ts）
4. **actionPower**：按文档校正所有行动类型的power值（actionDefs.ts）
5. **行动特殊效果**：按文档校正所有dodo/trust/nest变化量（combatReferee.ts）
6. **CLAIM_NEST_AREA**：补充目标nestInfluence -5效果

### Phase B：经济基础

让金币经济与文档一致，是所有付费行为的基础。

1. **挂机收益**：按Zog好感等级Lv1-5分别2/3/4/5/7 G每分钟（loungeIncome.ts）
2. **乞讨冷却**：改为10分钟（600000ms）（begging.ts）
3. **乞讨收益**：按Zog好感等级设置5档范围（begging.ts）
4. **指令计费**：改为 `length * 20` G/字（battleEngine.ts 或 commandGate.ts）
5. **首次REJECT免费**：增加attemptCount逻辑
6. **下注范围**：50-500G校验（betting.ts）
7. **preBattlePower公式**：`HP + ATK*3 + DEF*5 + SPD*4 - THREAT*2`（actorRoster.ts）
8. **赔率表**：按preBattlePower排名固定赔率x1.5/x2.0/x2.8/x3.8/x5.0（betting.ts）
9. **下注增加演员好感**：`floor(betAmount / 20)`（betting.ts → loungeStore）

### Phase C：道具闭环

让道具与文档一致，并实现冰箱升级联动。

1. **道具价格/效果**：按文档校正（items.ts）
2. **高能嘲讽电池**：改为350G，恢复60HP+护盾+TAUNT_1_ACTION（items.ts + battleEngine.ts useItem）
3. **劣质机油副作用**：20%概率触发STOMACHACHE_NO_ATTACK（combatReferee.ts + items.ts）
4. **回血间隔限制**：同一演员每轮只能被回血1次（initialState.ts track lastHealedAt + combatReferee.ts check）
5. **冰箱升级**：实现升级系统和Lv1-5次数1/2/3/4/5（shopStore + loungeStore + 设备升级cost表）
6. **破旧键盘升级**：实现字数上限5/8/12/20/30（loungeStore + battleStore commandInput校验）

### Phase D：战地记者

完善战地记者播报体系。

1. **阶段简报**：每N轮生成一次阶段摘要（reportGenerator.ts）
2. **演员羞辱记录**：accumulate shame tags in eventLog
3. **节目事故总结**：从eventLog提取最大事件（finalReport.ts）
4. **MVP/胜者/淘汰顺序**：与FinalScore对齐后通过reportGenerator输出

### Phase E：演员片酬 S

实现演员片酬的赚取和消费闭环。

1. **片酬账户**：ActorCombatState加salary字段，BattleResult计算后写入loungeStore
2. **名次片酬**：第1-5名分别60/35/20/10/0 S
3. **MVP片酬**：额外25 S，按damageDealt最高
4. **片酬消耗**：初级外观60S/高级外观180S/永久Prompt注入200S（shopStore + loungeStore）
5. **Actor好感礼物**：廉价粉丝牌/霓虹花篮/金主横幅的价格和好感值
