# Zog 好感度与战中反馈实施记录 0516

## 本次新增范围

1. Zog 好感礼物从 3 个扩充到 8 个。
2. 每个 Zog 礼物新增随机正反效果；基础好感一定生效，随机效果只改变本次净增加量。
3. 随机效果表现统一收敛为 Zog 脑袋上弹出的气泡；只区分正面气泡和负面气泡两套 UI，不为单个效果预留独立美术字段。
4. 客厅冰箱改为 Zog 交流入口，背包仍从右上角 BAG 入口进入。
5. 新增冰箱临时面板：好感等级、进度、8 个礼物、最近送礼气泡、Zog 聊天。
6. 战斗右侧 `Zog's Seat` 改为 Zog 静态角色位 + 向左冒泡的霓虹内发光气泡。
7. Zog 战斗短句会根据最新 DisplayEvent 变化：伤害、淘汰、回血、道具、导演广播、变异液、Prompt、状态、普通行动。
8. Zog lounge Prompt 改为 V1 人设的 V2 版本：飞鼠系可爱、傲娇陪伴、拾荒、跨维度懵懂、短句、禁止恋爱感。

## 边界保留

- 聊天仍不增加 Zog 好感。
- 战斗表现、观看节目、战报仍不增加 Zog 好感。
- Zog 好感不影响演员战斗数值。
- Zog 战中反馈只读 DisplayEvent，不调用 CombatReferee，不改 HP、金币、库存、演员好感、渡渡鸟和胜负。
- 当前没有 Zog 序列帧，所以战斗席位使用 `public/hub/zog.png` 静态资产占位。
- 送礼效果不设置 per-effect 动效字段；后续美术只需要先做 `positive` 和 `negative` 两种气泡接口。
